# 《小兵三国：从老虎机开始》策划案框架（纯广告版）

> 一句话：赵云与阿斗的「拼字三国 + 段位长线」，装上 Slotbound 的「3×3 转运盘 + 改运决策」引擎，压成 3 分钟一局的竖屏小游戏。
> 变现：**纯广告，无内购**。
> 版本：v0.1 框架稿   

## 0. 命名与合规

- 「老虎机」只作内部代号；对外名建议 **《小兵三国：从转运盘开始》**。
- 游戏内叫「转运盘 / 八卦盘」，UI 不出现转轴、7 字形、筹码、赔率、下注台。
- 概率公示、实名认证、防沉迷、隐私政策四项必须齐备。
- 纯广告变现走休闲小游戏备案路径（以平台最新政策为准），不接支付 SDK。

## 1. 基因配对

| 基因 | 来自 Slotbound | 来自赵云与阿斗 | 融合后 |
|------|----------------|---------------------|---------|
| 随机性 | 3×3 转盘抽单位 | 随机召 5 个单位 | **转运盘抽「字」** |
| 收集 | 单位合成 / 吞噬 | 拼字武将（赵+云） | **字既能当兵，也能拼将** |
| 战斗 | 自走棋自动战斗 | 护阿斗、3 条路 | 5×6 战场 + 3 路进攻 |
| 长线 | Roguelike 单局 | 54 段位 + 46 武器 | 30 段位 + 武器图鉴 |
| 变现 | 买断（Steam ¥37.8） | 纯广告 | **纯广告** |
| 时长 | 30–40 分钟 | 3–5 分钟 | **3 分钟** |

**关键创新**：让「字」成为唯一通用货币——同一个「赵」字，既是兵种、又是武将姓名的一半、还能当道具材料，转盘每落一个符号都要在三种价值间取舍。

## 2. 核心循环（一局 180 秒）

```
转运盘(3×3) → 连线出兵 / 集字出将 → 拖上战场 → 自动战斗
     ↑                                              ↓
  改运(锁/摇/换/天命) ←── 香火结算 ←── 波次推进(6波+Boss) ←──┘
```

| 时间 | 事件 |
|------|------|
| 0:00 | 开局送 1 次免费转，出 9 字 |
| 0:10 | 第一次连线，兵种上阵 |
| 0:30 | 第 1 波，教学提示 |
| 1:00 | 第 2 波结束，解锁「改运」按钮 |
| 1:30 | 第 3 波，Boss 预警 |
| 2:00 | 第 4 波，集齐「赵+云」召唤赵云（高光时刻） |
| 2:30 | 第 5 波，Boss 登场 |
| 3:00 | 结算：段位 +1，奖励 +4 |

## 3. 五个核心系统

### 3.1 转运盘（3×3）

- 每次转动落 **9 个符号**；横/竖/斜 **3 连** → 召唤 1 个对应兵种；4 连 → 2 个；整行 → 精英兵。
- **符号池 = 字**：刀/枪/弓/骑/盾/医/谋/炮（兵种）、赵/云/张/飞/关/羽（武将姓名字）、酒/书/铁/粮（道具）、「运」（万能字）。
- 权重：白 50% / 绿 28% / 蓝 14% / 紫 6% / 金 2%。
- 保底：连续 3 次未出紫 → 第 4 次必出紫（写入概率公示）。

### 3.2 拼字武将

- 盘面 9 字中**同时出现「姓」和「名」**（不限位置）→ 召唤该武将。
- 首批 12 将：赵云、张飞、关羽、马超、黄忠、吕布、曹操、刘备、孙尚香、甄宓、貂蝉、董卓（Boss）。
- 每将带专属武器（沿用赵云与阿斗数据）：赵云-龙胆亮银枪、关羽-青龙偃月刀、吕布-方天画戟……
- 武将靠局内拼出，不靠抽卡；收集感来自**图鉴解锁**。

### 3.3 合成与上阵

- **2 合 1**：两个同名同星 → 升 1 星，最高 5 星，每星 ×2.2 战力。
- 战场 **5×6 格、3 条路**；漏怪扣阿斗 1 命（3 命）。
- 单位自动攻击，玩家只做**摆位**与**改运**两个决策，单手可玩。

### 3.4 改运系统

| 道具 | 效果 | 次数 | 获取 |
|------|------|------|------|
| 锁格 | 锁定 1 格不刷新 | 每波 1 次 | 免费 1 次 + 广告 |
| 重摇 | 重转一次 | 2 次/局 | 广告 |
| 换字 | 换 1 个指定字 | 1 次/局 | 广告 |
| 天命 | 直接指定 1 个金色符号 | 1 次/局 | 每 5 段奖励 1 次 |

### 3.5 段位与长线

- **30 段位 × 4 地图**（巨鹿 / 云梦泽 / 虎牢关 / 赤壁）。
- 奖励 `10 + 4×id`（10 → 130），回合上限每 5 段 +25。
- 段位只影响 **AI 强度区间**（参考羽毛球高高手：0-7 → 72-79），不直接加数值。
- 长线收集：12 武将图鉴 + 46 武器图鉴 + 每日运势签 + 免费战令（50 级）。

**收入模型**（激励 eCPM 40 元、插屏 15 元）：
```
ARPDAU = 7 × 40/1000 + 0.5 × 15/1000 ≈ 0.29 元
```

|---|---------------|---------|

**LTV / CPA 生死线**

| 指标 | 估算值 |
|------|---------|
| ARPDAU | 0.29 元 |
| 平均生命周期 | 3–5 天 |

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| 三系统叠加（转盘+拼字+自走棋）认知过载 | 分步解锁：第 1 局只转盘+兵种，第 3 局开拼字，第 5 局开改运 |
| RNG 挫败（Slotbound 差评主要来源） | 保底紫 + 差 1 字免费重摇 + 动态 Boss HP（DPS 不足时 −15%） |
| 「老虎机」审核风险 | 对外改名「转运盘」，素材不出现转轴/7 字形 |
| eCPM 波动 | 穿山甲 + 优量汇 + 快手，多家聚合 + 动态底价 |
| 广告过多掉留存 | 单局 ≤3 次、插屏每 2 局 1 次，A/B 找平衡点 |
| 买量 ROI 打不正 | 主攻自然量与裂变，买量只做小规模测试 |

## 9. 与两个原作的关系

| 维度 | Slotbound | 赵云与阿斗 | 小兵三国 |
|------|---------|---------------|------------|
| 随机源 | 3×3 老虎机出单位 | 随机召 5 单位 | 3×3 转运盘出「字」 |
| 收集 | 吞噬合成 | 拼字武将 + 46 武器 | 字三用（兵/将/道具）+ 图鉴 |
| 长线 | 无（买断单机） | 54 段位 | 30 段位 + 免费战令 |
| 变现 | 买断 | 纯广告 | 纯广告 |
| 单局 | 30–40 分钟 | 3–5 分钟 | 3 分钟 |
> 不是换皮：Slotbound 的转盘只产出战斗单位，本作的转盘产出的是「字」——同一符号在兵种、武将、道具三种价值间切换，这是原作都没有的决策层。
