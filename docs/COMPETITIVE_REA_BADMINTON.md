# 《羽毛球高高手》逆向拆解（REA）

> 目标：拆解微信小游戏《羽毛球高高手》的技术栈、物理参数、段位/AI 数值、技能与商业化结构。
> 取证说明：微信小游戏包需要微信客户端缓存或 AppID（`servicewechat.com` 对非微信客户端一律 404）；本次以官方 Android APK（同游戏、同厂商，v6.3.1.408.405.1129）做静态拆解，数据表与小程序版大概率同源。
> 性质：仅用于研究与设计参考，不含美术、音频资源再分发。数据见 `docs/rea/badminton-master/`。   

## 0. TL;DR

1. 引擎是 **Cocos2d-x C++**：`libMyGame.so` 23.5MB（arm64），**没有 JS/Lua 脚本层**，逻辑全部在 native。
2. 物理只有 **6 组预设**（`worldParam.json`）：初速 `(60,38) / (70,-10) / (14,32)`，重力 `-50`，阻力 `0.3`。
3. 段位 **17 档**：奖杯 0 → 5000；AI 属性区间 0-7 → 72-79；350 杯后改成 **3 局 2 胜、每局 5 分**。
4. 击球判定是 **3 个矩形**（`rectNormalDown / rectNormalUp / rectMax`）+ 短/长球距离区间 + **12 帧延迟**。
5. 技能 **5 个**：Agility / StrongSmash / Endurance / Multi / Technic。
6. 商业化 **35 个 SKU，6–328 元**：金币、宝石、礼包、去广告、外观。
7. 第三方 SDK：Bugly、Umeng、YSDK（应用宝）、Midas 支付、Gradish 广告等，arm64 共 11 个 `.so`。
8. 包体 **77.9MB / 2935 个文件**：2005 png、286 csb、84 mp3、25 json。

## 7. 可复用结论（对 SAVE ODYSSEUS）

1. **段位门槛 + AI 区间映射**：奖杯阈值（0/100/200/350/500…）对应 AI 属性区间（0-7 → 72-79），比单纯加数值更容易做出"可感知的变强"；我们岛屿难度可直接套这个结构。
2. **赛制节奏**：350 杯前 1 局 5 分，之后 3 局 2 胜；单局时长正好落在 3–4 分钟，与我们的目标一致。
3. **手感参数化**：3 个判定矩形 + 12 帧延迟 + 短/长球距离区间，把"手感"拆成可调参数；我们的格挡/闪避窗口可以照此建表。
4. **定价带**：6 / 12 / 18 / 30 / 68 / 128 / 328，首充 6 元 + 中间档 18/30 元密集，是成熟小游戏的常见结构。
5. **技能少而深**：只有 5 个技能，但每个都有 ON/OFF 两套图标与等级，靠养成深度而不是数量。

## 9. 复现步骤

1. 应用宝详情页拿到 APK 直链（`imtt.dd.qq.com`，避开 `imtt2` 的 EdgeOne 反爬）。
2. `unzip ymqggs.apk`，读取 `assets/ResourcesV300/*.json` 与 `assets/GenerateDatas/*.bytes`。
3. 用 REA `inspect-artifact` 对 APK 做清单取证（2768 节点 / 2935 边）。
4. `libMyGame.so` 为 ARM64，REA 当前 `inspect-binary-layout` 仅支持 Linux x64，暂未做反汇编；如需深入可装 Ghidra/IDA 走 native 分析。
